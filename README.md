# Portscan

A Python tool that checks the status of TCP ports.

## About

This project was created for educational purposes and to reinforce knowledge of:

- Computer networking and the TCP protocol
- Python programming
- Command-line interfaces (CLIs)
- Error handling and network connections

## Initial Scope

The first version accepts an IP address or domain and a port, returning the port status.

## Responsible Use

The scanner must be used only in systems you own or have explicit permission to test.
